컴퓨터 기본 조작

실습에서 계속 쓰는 동작입니다. 이미 아는 것은 건너뛰세요. Windows 11 기준이며 Windows 10도 거의 같습니다.

하고 싶은 일이렇게 합니다
파일 탐색기 열기키보드 왼쪽 아래 ⊞ Windows 키를 누른 채 E를 누릅니다. 또는 화면 맨 아래 작업 표시줄의 노란 폴더 아이콘을 누릅니다.
창 두 개 나란히 놓기창 하나를 누르고 ⊞+←를 누르면 왼쪽 절반으로 갑니다. 오른쪽에 뜨는 다른 창을 누르면 나머지 절반을 채웁니다.
파일 여러 개 고르기하나씩: Ctrl을 누른 채 파일을 차례로 클릭. 폴더 안 전부: Ctrl+A
복사해서 붙여 넣기파일을 고르고 Ctrl+C → 넣을 폴더를 열고 빈 곳을 한 번 누른 뒤 Ctrl+V. 원본은 그대로 남습니다. 실습에서는 이 방법을 씁니다.
끌어다 놓기파일 위에서 마우스 왼쪽 단추를 누른 채 다른 폴더 창으로 옮긴 뒤 손을 뗍니다. 같은 드라이브 안에서는 이동(원본이 사라짐)입니다.
파일 끝 이름(.docx 등) 보이게파일 탐색기 위쪽 보기 → 표시 → 파일 확장명에 체크. 같은 메뉴의 숨긴 항목에 체크하면 숨김 폴더도 보입니다. Windows 10은 위쪽 보기 탭에 두 칸이 있습니다.
압축 파일(.zip) 풀기파일을 오른쪽 클릭 → 압축 풀기(또는 모두 압축 풀기) → 풀 위치를 고르고 압축 풀기.
앱 다시 찾기화면 아래 ⊞ 시작 단추를 누르고 ChatGPT를 입력하면 나옵니다. 오른쪽 클릭 → 작업 표시줄에 고정하면 다음부터 한 번에 엽니다.

실습 내내 쓰는 화면 배치

  1. ChatGPT 앱을 열고 ⊞+←로 화면 왼쪽 절반에 놓습니다.
  2. 파일 탐색기(⊞+E)를 열고 바탕 화면 → AI연수실습으로 들어갑니다.
  3. 파일 탐색기를 누르고 ⊞+→로 오른쪽 절반에 놓습니다.

이렇게 놓으면 오른쪽에서 파일을 넣고, 왼쪽에서 "처리해"라고 쓰고, 다시 오른쪽에서 결과를 여는 흐름이 한눈에 보입니다.

설치하고 Codex 열기

학교 PC는 설치가 막혀 있을 수 있어 연수 전에 해 옵니다. 실습 폴더(AI연수실습.zip)는 강사가 메신저나 공유 드라이브로 미리 나눠 줍니다.

설치 1 / 3 · 약 5분

ChatGPT 데스크톱 앱 설치

  1. 인터넷 창(크롬, 엣지 등)을 열고 주소창에 chatgpt.com/download를 입력합니다.
  2. Windows용 다운로드 단추를 누릅니다. Microsoft Store 앱이 저절로 열립니다. "Microsoft Store를 여시겠습니까?"라고 물으면 열기를 누릅니다.
  3. Store 화면의 받기(또는 설치)를 누릅니다. 파란 막대가 끝까지 차면 설치가 끝난 것입니다.
  4. 열기를 누릅니다. 다음부터는 시작 단추에서 ChatGPT를 찾아 엽니다.

Microsoft Store가 막힌 학교 PC는 정보 담당 선생님께 설치를 부탁하거나 개인 노트북을 씁니다.

설치 2 / 3 · 약 2분

ChatGPT 계정으로 로그인

  1. 앱 첫 화면에서 로그인(Sign in)을 누릅니다.
  2. 인터넷 창이 열리면 평소 쓰는 ChatGPT 계정으로 로그인하고 허용을 누릅니다. 계정이 없으면 같은 화면에서 이메일로 가입합니다.
  3. "앱으로 돌아가기" 같은 안내가 뜨면 누릅니다. 앱 화면으로 돌아오면 끝입니다.

무료 계정도 쓸 수 있지만 보조 AI 여럿이 동시에 일하면 사용량이 빨리 찹니다. 실습에는 Plus 이상 요금제를 권합니다.

설치 3 / 3 · 약 1분

왼쪽 위에서 Codex로 바꾸기

  1. 앱 왼쪽 세로 메뉴(사이드바) 맨 위의 ChatGPT ▾를 누릅니다.
  2. 펼쳐진 목록에서 Codex를 누릅니다.
  3. 사이드바에 New chat, Projects, Scheduled, Plugins가 보이면 성공입니다.

처음 Codex를 열 때 Windows가 "이 앱이 디바이스를 변경하도록 허용하시겠어요?"라고 물을 수 있습니다. Codex가 안전 구역(샌드박스)을 만드는 과정이라 예를 누릅니다. 관리자 비밀번호를 물으면 정보 담당 선생님께 부탁합니다.

Canva 연결이 안 되어 있으면 구성안과 학습지까지만 만들고 확인필요 메모를 남깁니다. Canva 연결을 마친 뒤 "수업PPT만 다시 처리해"라고 합니다.

수행평가 피드백: 반마다, 10명씩 나눠 동시에

실습 F · 10분

한꺼번에, 그리고 정해진 시간에 저절로

여러 폴더에 파일을 넣고 "처리해"라고 하면 폴더마다 AI가 하나씩 동시에 일합니다. 예약을 걸면 말하지 않아도 정해진 시간에 넣는곳을 확인합니다.

① 여러 폴더 동시 처리

  1. 예시자료의 시험문제 파일 4개와 피드백 파일 3개를 다시 복사해 각 넣는곳에 붙여 넣습니다.
  2. New chat에서 "처리해"를 입력합니다.
  3. 폴더별 AI 2개가 동시에 일하고 마지막에 폴더별 결과 표가 나옵니다. 이전 결과는 지워지지 않고 새 파일이 추가됩니다.

② 예약 걸기

  1. 같은 대화에 아래 문장을 복사해 붙여 넣고 Enter.
  2. 사이드바 Scheduled를 눌러 예약이 생겼는지 봅니다. 실행할 때마다 기록이 여기에 쌓입니다.
  3. 시간을 바꾸거나 멈출 때는 Scheduled에서 그 예약을 누르거나, 대화로 "예약 멈춰 줘"라고 씁니다.
입력
평일 오후 4시 30분마다 시험문제와 수행평가피드백 넣는곳을 확인해서 새 파일이 있으면 처리해 줘. 없으면 아무것도 하지 마.

예약은 컴퓨터가 켜져 있고 ChatGPT 앱이 열려 있을 때만 돕니다. 선생님이 자리에 없는 동안 실행되므로 승인을 받을 수 없어, 폴더 밖이나 인터넷이 필요한 단계는 실패할 수 있습니다. Canva가 필요한 PPT·포스터는 직접 "처리해"로 돌립니다.

실습마다

결과 확인하고 고치기

결과 파일 여는 두 가지 방법

  1. 파일 탐색기: 작업 폴더의 결과를 열고 파일을 두 번 클릭합니다. 워드·엑셀로 바로 열립니다. 파일 이름 앞의 날짜(예: 2026-11-20_)로 언제 만든 것인지 압니다. "보호된 보기"가 뜨면 편집 사용을 누릅니다.
  2. 앱 안에서: 대화에 표시된 결과 파일을 누르면 대화 옆에서 미리 볼 수 있습니다. 미리보기의 특정 부분을 짚어 그 부분만 고쳐 달라고 할 수도 있습니다.

고치는 세 가지 방법

방법언제예
같은 대화에서 말하기몇 군데만 바꿀 때"7번은 ②와 ④가 둘 다 정답으로 읽혀. 고쳐 줘"
워드·엑셀에서 직접문장 몇 개 다듬을 때결과 파일을 열어 바로 수정·저장
다시 처리해설정을 바꾸고 처음부터"시험문제만 다시 처리해" → 파일 이름 끝에 _2

꼭 보는 두 파일

  1. 결과\확인필요.txt: 처리하지 못한 파일과 이유가 적혀 있습니다(예: 한글 파일이라 못 읽음, 이름 열 있음). 두 번 클릭하면 메모장으로 열립니다. 이 파일이 없으면 문제없이 끝난 것입니다.
  2. 0_설정\처리기록.csv: 언제 무엇을 처리했는지 한 줄씩 쌓입니다. 엑셀로 열립니다. 예약 실행 결과도 여기서 확인합니다.

내 업무 폴더로 옮겨 쓰기

실습 폴더를 그대로 업무용으로 씁니다. 예시만 지우고 내 파일을 넣으면 됩니다.

  1. 폴더 옮기기: 바탕화면의 AI연수실습 폴더를 Ctrl+C → 파일 탐색기 왼쪽 문서(또는 D 드라이브)를 열고 Ctrl+V. 붙여 넣은 폴더를 오른쪽 클릭 → 이름 바꾸기 → AI업무. 예시자료 폴더와 각 결과·완료 폴더 속 파일은 지워도 됩니다. 넣는곳·결과·완료 폴더 자체는 남깁니다.
  2. 새 프로젝트로 연결: Projects → Add new project → 문서 → AI업무 한 번 클릭 → 폴더 선택.
  3. 설정 바꾸기: 0_설정\기본설정.xlsx에서 내 학년·교과·학교 이름을 넣고 저장·닫기.
  4. 양식 채우기: 입력양식의 엑셀을 복사해 채우고, 이름을 알아보기 쉽게 바꿔(예: 2학년1반_점수표.xlsx) 넣는곳에 넣습니다.
  5. 자료 폴더 연결(선택): 수행평가 자료가 다른 폴더에 있으면 Edit project → Add folder로 붙이고, AI업무를 기본 폴더로 둡니다.
  6. 반복 업무는 예약: 매주 같은 시간에 할 일은 실습 F처럼 예약합니다.

새 업무 추가하기 (예: 공문 요약)

  1. "AI업무 폴더에 5_공문요약 작업 폴더를 넣는곳·결과·완료와 함께 만들어 줘"라고 씁니다.
  2. 입력창에 $skill-creator를 입력하고 이어서 아래 예시처럼 하고 싶은 일을 설명합니다. 질문이 나오면 답합니다.
  3. "업무 매뉴얼 표에 5_공문요약을 추가해 줘"라고 쓰면 다음부터 "처리해"에 포함됩니다.
$skill-creator 뒤에 입력 예시
공문 PDF나 워드를 넣으면 제목, 마감일, 해야 할 일, 담당자를 표로 정리한 워드 파일을 만드는 스킬을 만들어 줘. 폴더는 5_공문요약이야.

동료와 나눌 때는 AI업무 폴더에서 결과·완료 속 파일과 개인 자료를 지우고, 폴더를 오른쪽 클릭 → 압축(ZIP) 파일로 압축해 보냅니다. 받은 사람은 압축을 풀고 프로젝트로 연결하면 같은 방식으로 씁니다.

자주 나오는 문제

증상해결
"처리해"에 엉뚱한 답을 함사이드바의 프로젝트를 누른 뒤 New chat을 열었는지 봅니다. Edit project에서 실습 폴더가 primary(기본 폴더)인지, 업무 매뉴얼(AGENTS.md)이 그 폴더 맨 위에 있는지 확인합니다.
한참 지나도 진행이 없음화면을 아래로 내려 승인 요청이 기다리고 있는지 봅니다. 없으면 멈춤(■)을 누르고 "이어서 처리해"라고 씁니다.
"파일을 열 수 없다"고 함엑셀·워드에서 그 파일이 열려 있으면 닫고 다시 "처리해"라고 씁니다.
한글(.hwp) 파일을 넣었더니 건너뜀한글에서 파일 → 다른 이름으로 저장 → 파일 형식을 Word 문서(.docx) 또는 PDF로 바꿔 저장해 넣습니다.
이름 열 때문에 멈춤점수표에서 이름 열을 지우고 번호만 남겨 다시 넣습니다.
결과가 워드·엑셀이 아니라 .html·.csv로 나옴워드·엑셀을 만드는 도구가 PC에 없는 경우입니다. .html은 두 번 클릭하면 인터넷 창에서 열리고 내용을 복사할 수 있습니다. 계속 워드·엑셀로 받으려면 "Python을 설치해 줘"라고 쓰면 Codex가 설치를 돕습니다(관리자 승인이 필요할 수 있음).
파일 이름에 .docx 같은 끝 이름이 안 보임파일 탐색기 보기 → 표시 → 파일 확장명에 체크합니다.
Microsoft Store가 열리지 않음학교 PC 정책으로 막힌 경우입니다. 정보 담당 선생님께 설치를 부탁하거나 개인 노트북을 씁니다.
처음 실행 때 관리자 승인 창이 뜸Codex가 안전 구역을 만드는 과정입니다. 예를 누르고, 관리자 비밀번호가 필요하면 정보 담당 선생님께 부탁합니다.
왼쪽 위에 Codex 선택지가 없음Microsoft Store → 라이브러리 → 업데이트 받기로 앱을 최신 버전으로 바꾼 뒤 다시 엽니다.
Canva 작업을 건너뜀Plugins에서 Canva 설치·로그인을 마쳤는지 확인하고 New chat으로 새 대화를 엽니다.
예약이 안 돌았음그 시간에 컴퓨터가 꺼져 있었거나 앱이 닫혀 있었는지 봅니다. Scheduled의 실행 기록과 처리기록.csv를 확인합니다.
"사용량 한도" 안내가 뜸요금제 한도에 걸린 경우입니다. 옆 사람과 짝 실습하거나 시간을 두고 다시 합니다.
