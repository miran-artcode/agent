학습 여정

    함께 배우는 바이브코딩 · with Claude

    코딩을 배우지 않습니다.
    말하는 법을 배웁니다.

    AI(Claude)에게 원하는 것을 평범한 말로 설명하면, 작동하는 도구가 됩니다. 수업은 물론 교무·학급·집안일·일정·가계부까지 — 끝까지 따라오면 누구나 ‘내게 필요한 도구’를 직접 만들 수 있어요.

    말로 요청→ 결과 확인→ 수정 요청↺ 완성

    🎒 준비물

    Claude 계정 하나면 됩니다. 무료 요금제로 바로 시작할 수 있어요. 노트북이나 데스크톱 브라우저를 권장합니다.

    claude.ai 새 탭에서 열기 ↗

    🧭 이렇게 진행돼요

    10단계를 차례로 따라가며, 각 단계를 마치면 왼쪽 여정에 표시됩니다. 진도는 자동으로 기억돼요.

    개념 → 마인드셋 → 프롬프트 설계 → 첫 실습 → 반복 → 에러 고치기 → 검증 → 활용 사례 → 내 도구 → 학생 프로젝트

    STEP 01

    바이브코딩이란?

    내가 원하는 것을 평범한 ‘말’로 설명하면, AI가 대신 코드를 만들어 주는 방식입니다. 문법을 외울 필요가 없어요.

    3단계 흐름

    ① 말로 설명→ ② AI가 코드 작성→ ③ 확인하고 다듬기↺ 반복

    ‘이런 걸 만들어줘’라고 요청하면 작동하는 결과가 나오고, 마음에 들 때까지 대화로 고쳐 나갑니다.

    비유로 이해하기

    🍳 요리 — 주문하기레시피를 외우는 대신, 셰프에게 ‘이런 요리 주세요’라고 주문합니다.
    🧭 내비게이션길을 다 외우지 않아도, 목적지만 말하면 경로를 안내받습니다.
    🗣️ 통역사내가 한 말을 컴퓨터가 알아듣는 언어로 옮겨 주는 통역사입니다.
    🏗️ 건축주벽돌을 직접 쌓는 대신, 원하는 집의 모습을 설명하는 건축주가 됩니다.

    무엇을 만들 수 있나요?

    ✓ 잘 만들어요퀴즈·게임·타이머·계산기·차트·일정표처럼 ‘한 화면에서 도는’ 도구
    △ 아직 어려워요학교 시스템 연결, 로그인·결제, 여러 사람의 자료를 한곳에 모으는 일

    작게·구체적으로 시작할수록 성공 확률이 높아요. ‘우리 반 발표자 뽑기’처럼요.

    ✅ 한 문제로 확인

    바이브코딩에서 가장 중요한 ‘실력’에 가까운 것은?

    STEP 02

    마인드셋 — 한 줄이면 끝이 아니다

    바이브코딩의 진짜 모습은 ‘대화와 반복’입니다. 프롬프트 한 줄로 완성되는 게 아니라, 결과를 보고 여러 번 고쳐 나가는 과정이에요.

    ✕ 흔한 오해

    · 한 줄만 넣으면 완성된다
    · AI가 알아서 다 해준다
    · 나온 결과를 그대로 쓰면 끝

    ✓ 실제 모습

    요청→ 확인→ 수정↺

    완성은 첫 응답이 아니라, 여러 번의 수정 끝에 나옵니다.

    ✅ 참 / 거짓

    “프롬프트 한 줄만 잘 쓰면 바이브코딩은 끝난다.”

    💡
    핵심 — 문법이 아니라, ‘무엇을 원하는지’ 명확히 말하고 끈기 있게 고치는 능력이 실력입니다.

    STEP 03 · 핵심 도구

    프롬프트, 6가지로 ‘설계’하기

    전문가는 한 문장으로 끝내지 않습니다. 6가지를 정해 주면 AI가 멋대로 추측할 일이 줄어, 한 번에 ‘바로 쓸 만한’ 결과가 나와요. 먼저 차이를 보고, 직접 설계해 봅니다.

    ‘한 줄’ vs ‘전문가 프롬프트’

    같은 걸 부탁해도, 어떻게 쓰느냐에 따라 결과가 완전히 달라집니다.

    ✕ 누구나 쓰는 한 줄
    발표자 룰렛 만들어줘

    대충은 만들어 주지만 — 명단 수정, 중복 방지, 큰 글씨, 모바일은 빠지기 일쑤라 매번 다시 부탁하게 됩니다.

    ✓ 전문가 프롬프트 (6요소)
    역할: 너는 교실에서 바로 쓸 웹 도구를 만드는 프론트엔드 개발자야. 모르는 부분은 합리적으로 가정하고, 최종 결과를 먼저 보여 줘.

■ 만들 것: 학생 이름 중 무작위로 한 명 뽑는 ‘발표자 룰렛’ 웹페이지
■ 사용 상황: 28명 학급, 교사가 노트북→TV로, 수업 중 1~2초 안에 한 명
■ 핵심 기능:
   - 이름을 줄바꿈으로 입력·수정(기본값 학생1~28)
   - ‘뽑기’를 누르면 1초 애니메이션 후 당첨자를 화면 중앙에 크게 표시
   - ‘뽑은 사람 제외’ 토글, ‘초기화’ 버튼
■ 예외·규칙: 이름이 없거나 모두 뽑혔으면 에러 없이 안내
■ 디자인·접근성: 아주 큰 글씨·높은 대비·큰 버튼, 모바일 반응형
■ 출력·제약: 외부 라이브러리 없이 단일 HTML 파일, 인터넷 없이도 작동
■ 완료 기준: 위 동작이 다 되는지 점검하고, 빠뜨린 가정이 있으면 먼저 물어봐 줘.

    동작·예외·디자인·제약·완료 기준까지 정해 주니, 거의 한 번에 완성됩니다. 이게 ‘바이브코딩 실력’이에요.

    직접 설계하기 — 6요소 빌더

    템플릿: 
    왼쪽 빈칸을 채우거나 템플릿을 눌러 보세요. 여기에 ‘전문가 프롬프트’가 완성됩니다.

    이 프롬프트를 복사해 claude.ai 대화창에 붙여넣으세요. 모든 칸을 다 채울 필요는 없지만, 많이 정할수록 결과가 좋아집니다.

    ✍️ 기억할 3가지

    ① 구체적으로‘퀴즈 만들어줘’보다 동작·숫자·상황까지 콕 집어 주세요.
    ② 예시·기준을 주기원하는 모양과 ‘완료 기준’을 알려 주면 추측이 줄어요.
    ③ 한 번에 하나씩한꺼번에 다 말하기보다, 만들고 본 뒤 하나씩 고치세요.

    STEP 04 · 실습 ①

    첫 작품: 발표자 룰렛

    claude.ai에 접속해, 아래 순서대로 직접 만들어 봅니다. 오른쪽 ‘Artifact’ 패널에서 결과가 바로 작동해요.

    따라 하기 6단계

    1. claude.ai 접속 → 새 대화 시작
    2. 아래 프롬프트를 그대로 붙여넣기
    3. 오른쪽 Artifact 패널에서 직접 작동 확인
    4. 채팅으로 2~3회 수정 (반복이 핵심)
    5. 우리 반 내용으로 교체 — 실명 대신 번호·별명
    6. ‘Publish’로 링크 만들어 공유

    붙여넣을 첫 프롬프트

    이름을 입력하면 무작위로 한 명을 뽑아 주는 ‘발표자 룰렛’을 만들어줘. 버튼을 누르면 원판이 돌아가고, 당첨자 이름이 화면 중앙에 크게 표시되는 웹페이지로.

    이어서 — 수정 요청 예시

    뽑힌 사람은 다시 안 뽑히게 해줘.
    글씨를 더 크게, 모바일에서도 잘 보이게 해줘.
    🛠️
    막히면? 빨간 에러가 떠도 당황 금지 — 메시지를 그대로 복사해 ‘이 오류 고쳐줘’라고 붙여넣으면 Claude가 직접 고쳐 줍니다.

    직접 해보기

    • claude.ai에 접속해 새 대화를 열었다
    • 예시 프롬프트를 붙여넣었다
    • 오른쪽 Artifact에서 직접 작동해 봤다
    • 수정 요청을 한 번 이상 해봤다
    • 내 반 내용으로 바꿔봤다

    STEP 05

    반복·수정의 기술

    한 번에 완벽하지 않아도 괜찮아요. 아쉬운 점을 골라 보세요. 바로 쓸 수 있는 ‘수정 요청’ 프롬프트를 만들어 드립니다.

    무엇이 아쉬운가요?

    위에서 아쉬운 점을 하나 골라 보세요.

    팁: 한 번에 하나씩 고치면 결과를 확인하기 쉬워요. 고치고 → 보고 → 또 고치고를 반복하세요.

    STEP 06

    에러가 나면, 대화로 고치기

    빨간 글씨가 떠도 고장이 아니에요. AI가 만든 건 AI가 고칩니다. 핵심은 ‘무엇이 잘못됐는지’를 잘 전달하는 거예요 — 추측하지 말고 ‘증거’를 주세요.

    고치는 3단계

    1. 한 가지만 정한다 — ‘버튼이 안 눌린다’처럼 증상을 하나로 좁히기
    2. 증거를 그대로 준다 — 빨간 에러 메시지를 복사하거나, 화면 스크린샷을 첨부
    3. 증상으로 요청한다 — ‘이렇게 고쳐’가 아니라 ‘이런 증상인데 원인을 찾아 고쳐줘’

    그대로 복사해 쓰는 디버깅 프롬프트

    ① 빨간 에러가 떴을 때

    방금 화면에 이런 빨간 오류가 떴어:
[여기에 에러 메시지를 그대로 붙여넣기]
어느 부분이 왜 문제인지 한 줄로 설명하고, 고쳐서 다시 만들어줘.

    ② 에러는 없는데 동작이 이상할 때

    에러는 안 뜨는데, [증상: 예 - ‘뽑기’ 버튼을 눌러도 아무 일이 없어].
원인을 찾아서 고쳐줘. 바꾼 부분도 한 줄로 알려줘.

    ③ 화면 모양이 의도와 다를 때 (스크린샷 첨부)

    이 화면 스크린샷을 첨부했어. 빨간 동그라미 친 부분이 의도와 달라.
이렇게 보여야 해: [원하는 모습].
그대로 고쳐서 다시 만들어줘.
    🧭
    자주 겪는 상황 — 한 번에 하나씩 고치기 / 고치다 더 나빠지면 ‘방금 변경은 되돌리고 원래대로’ / 같은 오류가 계속 반복되면 ‘처음부터 더 단순하게 다시 만들어줘’.

    STEP 07

    검증과 안전

    AI는 빠르지만 늘 옳지는 않습니다. ‘작동한다’와 ‘제대로 된다’는 다릅니다. 강하게 활용하되, 반드시 검증하세요.

    🎓
    비유 — AI는 ‘똑똑한 실습생’. 유능하지만 경험은 적은 실습생처럼, 일은 빠르되 결과는 반드시 검토가 필요합니다.

    검증 체크리스트

    • 직접 실행해 결과를 끝까지 확인했다
    • 학생 입장에서 오류·예외 상황을 점검했다
    • 개인정보·민감정보는 넣지 않았다
    • ‘작동한다’와 ‘제대로 된다’를 구분했다
    🔒
    개인정보 · 공개 주의
    ‘Publish’로 공개한 링크는 검색에 노출될 수 있어요. 학생 이름·정보가 든 결과물은 공개하지 말고, 내부 공유는 다운로드나 Remix를 쓰세요.
    📰
    2026년에 실제로
    검토 없이 공개한 앱에서 대규모 정보 유출 사고가 잇따랐습니다(몰트북·Lovable 등). 검증은 선택이 아니라 필수예요.
    💾
    저장에 주의 — 만든 도구는 새로고침하면 입력한 내용이 사라질 수 있어요. 중요한 자료는 따로 보관하거나, ‘입력한 내용이 저장되게 해줘’라고 이어서 요청하세요.

    STEP 08 · 둘러보기

    활용 사례 — 수업부터 일상까지

    바이브코딩은 수업 자료만이 아니라 교무·학급·일정·집안일·가계까지 도와줍니다. 마음에 드는 프롬프트를 복사해 claude.ai에 붙여넣어 보세요. 숫자·이름은 내 상황에 맞게 바꾸면 됩니다.

    🗂️ 교무·행정

    가정통신문 초안정중한 말투로 빠르게 
    다음 주 현장학습 안내 가정통신문 초안을 만들어줘. 날짜·장소·준비물·회신 기한을 넣고, 학부모님께 보내는 정중한 말투로.
    수행평가 점수 계산기가중치 합산·등급 자동 
    수행평가 4개 항목 점수를 입력하면 가중치(30·30·20·20%)로 합산해 환산 점수와 등급을 보여주는 계산기를 만들어줘. 등급 기준은 내가 바꿀 수 있게. 웹페이지로.
    상담 신청 화면희망 시간 받아 목록화 
    학부모 상담 희망 시간을 고르는 간단한 신청 화면을 만들어줘. 요일·시간대를 선택하면 아래 목록에 쌓이게. 웹페이지로.

    🏫 학급경영

    자리 배치 뽑기무작위 + 다시 섞기 
    우리 반 28명 자리를 무작위로 배치해 주는 도구를 만들어줘. 다시 누르면 새로 섞이고, 이름 목록은 내가 바꿀 수 있게. 웹페이지로.
    1인 1역 배정역할을 공평하게 
    학급 역할 12개를 학생들에게 무작위로 배정하는 도구를 만들어줘. 이름과 역할 목록은 내가 바꿀 수 있게. 웹페이지로.
    칭찬 점수판모둠 점수 + 그래프 
    모둠별 칭찬 점수를 +1 버튼으로 올리고 막대그래프로 보여주는 화면을 만들어줘. 모둠 수와 이름은 내가 정할 수 있게. 웹페이지로.

    🗓️ 개인 일정·생산성

    주간 할 일 보드체크하면 줄이 쫙 
    이번 주 할 일을 요일별로 적고, 체크하면 줄이 그어지는 투두 보드를 만들어줘. 완료한 개수도 보여주게. 웹페이지로.
    내 시간표오늘 요일 강조 
    내 주간 수업 시간표를 표로 만들어줘. 요일×교시 칸에 과목과 교실을 넣고, 빈 시간은 회색, 오늘 요일은 강조해서. 웹페이지로.

    👨‍👩‍👧‍👦 가족·자녀

    가족 주간 스케줄사람별 색 구분 
    우리 가족(엄마·아빠·아이 둘) 주간 일정을 한눈에 보는 표를 만들어줘. 사람별 색을 다르게 하고, 오늘 칸을 강조. 모바일에서도 잘 보이게.
    아이 학원 관리오늘 갈 학원·픽업 시간 
    아이 학원 시간표(요일·시간·과목·장소)를 보여주고, 오늘 갈 학원을 알려 주는 화면을 만들어줘. 픽업 시간도 표시하고, 목록은 내가 바꿀 수 있게. 휴대폰에서 보기 좋게.

    💰 생활·금전

    식사·운동 기록 다이어리한 주를 돌아보기 
    매일 먹은 것과 운동을 적고, 한 주를 그래프로 돌아보는 기록 다이어리를 만들어줘. 점수나 목표 없이 기록·돌아보기 용도로. 웹페이지로.
    한 달 가계부지출 합계·남은 예산 
    이번 달 지출을 카테고리별(식비·교통·여가 등)로 입력하면 합계와 남은 예산, 비율 그래프를 보여주는 가계부를 만들어줘. 카테고리는 내가 바꿀 수 있게. 웹페이지로.
    월급 분배 계산기저축·지출 비율 자동 
    월급을 입력하면 저축·고정지출·생활비를 정해 둔 비율(예: 50·30·20%)로 자동으로 나눠 보여주는 계산기를 만들어줘. 비율은 내가 바꿀 수 있게. 웹페이지로.

    STEP 09 · 졸업 과제

    내 도구 만들기 — 수업부터 일상까지

    이제 직접 차례입니다. 상황을 하나 고르면 4요소가 채워져요. 내 상황에 맞게 고친 뒤 ‘나만의 프롬프트’를 완성하고, Claude로 만들어 보세요.

    과목을 고르고 빈칸을 채워 보세요.
    • 내 교과용 프롬프트를 완성했다
    • Claude로 만들어 작동을 확인했다
    • 검증 체크리스트로 점검했다
    • 공유(Publish/링크) 준비를 마쳤다
    📋
    내 자료 넣기 — 단어 목록·문항 같은 내 자료는 프롬프트에 바로 붙여넣거나, 만든 뒤 ‘여기에 이 목록을 넣어줘’라고 이어서 요청하세요. 학생은 실명 대신 번호·별명으로.

    STEP 10 · 확장

    학생이 직접 만들게 하기

    가장 강력한 활용은 교사가 아니라 학생이 ‘만드는 사람’이 되는 거예요. 한 차시 흐름과 평가 루브릭을 그대로 가져다 쓰세요.

    한 차시 수업 흐름 (예: 45분)

    1. 문제 찾기 (5분) — ‘우리 반·내 생활에서 불편한 것’을 한 가지 정하기
    2. 설계 (10분) — 6요소(맥락·목표·기능·예외·디자인·출력)로 프롬프트 쓰기
    3. 제작 (15분) — Claude로 만들고 오른쪽 Artifact에서 작동 확인
    4. 개선 (10분) — 검증 체크 + 결과를 보며 2~3회 수정(반복)
    5. 공유 (5분) — 짝과 시연하고 한 가지씩 피드백 주고받기

    평가 루브릭

    평가 요소상중하
    문제 정의구체적이고 실제 필요에서 출발주제는 있으나 다소 모호문제가 불명확
    프롬프트 설계목표·기능·제약을 구조적으로 작성일부 요소만 포함한 줄 요청에 그침
    반복·개선결과를 검토해 의미 있게 여러 번 수정한두 번 수정거의 수정 안 함
    검증·책임오류·예외·개인정보까지 점검작동 여부만 확인확인하지 않음
    공유·설명무엇을 왜 만들었는지 설명결과만 보여줌공유하지 않음
    🧑‍🏫
    운영 팁 — 모둠 2~3명에 기기 1대 / 학생은 실명 대신 번호·별명 / ‘결과만 복사·제출’을 막기 위해 프롬프트와 수정 과정도 함께 제출하게 하세요. 과정이 곧 평가입니다.
